# Client Review v1 — Refined Spec

Original raw notes (Spanish, shorthand) refined into actionable items through a
grilling session on 2026-11-09. Each item below carries the original note for
traceability, the resolved decision, and concrete acceptance criteria/pointers
to the relevant code. Items explicitly excluded from this pass are listed at
the bottom with the reason.

## Home

### 1. Add French as a locale
> Original: "Agregar arabe y frances"

**Decision:** Add French (`fr`) only, as a standard LTR locale — same effort
as the existing `es`/`pt` rollout. **Arabic is out of scope for this pass**,
tracked separately: the app has zero RTL support today (no `dir` attribute,
no mirrored layouts/icons anywhere), so Arabic needs its own dedicated
project, not a bullet in this list.

**Work:**
- Add `"fr"` to `lib/i18n.ts` locales + `localeLabels`.
- Add `lib/dictionaries/fr.json` (mirrors `en.json`'s shape).
- French CMS content stays empty/untranslated until an editor fills it in —
  same fallback-to-English behavior as any other locale with missing
  translations.

### 2. AI-assisted translation tool

## Initiatives

### 10. Initial rotation animation
> Original: "Animación inicial de rotación"

**Decision:** The radial graph (`components/common/InitiativesGraph.tsx`)
should rotate/settle into its resting position once on page load — a
one-time entrance animation, not a loop.

### 11. Normalize "Interventions" → "Initiatives" (UI copy only)
> Original: "Normalizar todo a 'initiatives' en vez de 'interventions'"

**Decision:** Scoped to **our own hardcoded UI chrome strings** (dictionary
files `en`/`es`/`pt`/`fr`) — e.g. the graph's "Interventions" ring legend
(`interventionsLabel` key, used by both `InitiativesExplorer` and
`FocusAreasBreakdown` dictionaries).

**Explicitly NOT in scope:**
- The Sanity document type itself stays named `intervention` — renaming it
  would touch every existing document's `_type` and require a migration.
- CMS-authored body/card text (e.g. a Results-page stat card currently
  labeled "Interventions", or "Each line is a connection between
  interventions" on the Initiatives graph footer) is content, not code —
  left for the content owner to edit in Studio.

### 13. Focus-area filter dropdown truncates "National Identity & Vision"
> Original: "Menu: se corta en national vision, tiene que ser más ancho"

**Decision:** Confirmed live on `/initiatives` — the focus-area filter
(`components/ui/select.tsx`, used by `InitiativesExplorer` and others) clips
the longest option. Fix the shared `Select` component so its open panel
sizes to its widest option with no wrapping — fixes every place this
dropdown is used, not just this one instance.

### 14. Organic (not straight) connector line
> Original: "Conector linea más organico, no recto."

**Decision:** Root cause found — `ribbonPath()` in `InitiativesGraph.tsx`
degenerates to a mathematically straight line whenever both ends share the
same angle (the common "dot → its own primary Focus Area arc" case, since
both bezier control points end up on that same angle too). Fix: offset the
control points sideways by a small angle so the curve bows into a **gentle
S-curve** — subtle, not a dramatic loop.

### 16. Signals of Change: "Now" ends in an arrow, not a dot
> Original: "Signals of change: Now en vez de un punto, que termine en flecha"

**Decision:** `TimelineTick` in `components/common/SignalsOfChange.tsx`
renders the same small dot for every tick, including "Now". Change so the
**horizontal track itself terminates in an arrowhead** at the "Now" end
(implying continuation into the future) — every other tick (years,
milestones) stays as-is, only the track's end cap and the "Now" tick's
marker change.

### 21. Graph rotates when a Focus Area is clicked
> Original: "Gráfico: cada vez que se apreta algo que se gire."

**Decision:** Applies to the **Focus Areas Breakdown graph** (the "What's
already happening" block, `components/common/InitiativesGraph.tsx` in its
arc-selection mode — currently live on the Collaborate page, despite this
note sitting under "Results" in the source doc; the doc's section labels
don't line up 1:1 with the site's actual pages). Clicking a Focus Area's arc
should **rotate the whole graph** so the selected arc moves to a fixed
position (top/north) — not the Initiatives page's main graph, and not a
per-dot rotation.

### 23. "From fragmentation to Coherence" in bold
> Original: "From framagention to coherence en bold."

**Decision:** Confirmed live on Collaborate (`ShiftInLogicRow` title inside
the "A shift in logic" section). Apply `font-bold` to the row-title style in
general — all three rows ("From fragmentation to Coherence", "From linear to
systemic", "From static to adaptative"), not a one-off for this row's text.

### 24. Map: visible borders on the islands
> Original: "Mapa configurar para que sean bordes."

**Decision:** Confirmed live on the Territory map (Collaborate page) — the
São Tomé/Príncipe/Santo António landmasses render as flat fills with no
outline, blending into the grey ocean background. Add a **visible
border/coastline stroke** to the land layer in the MapLibre/OpenFreeMap map
style.
