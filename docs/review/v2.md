## Bigger, separately-scoped projects

### Arabic locale + RTL support
> Original: "Agregar arabe y frances" (French shipped in v1; Arabic split out)

The app has no RTL support today — no `dir` attribute anywhere, no mirrored
layouts/icons/spacing. Adding Arabic properly means an RTL audit and likely
adjustments across most components (nav, cards, the radial graphs, the
Territory map popover direction, etc.), not just a 6th entry in
`lib/i18n.ts`. Scope as its own project: audit → RTL utility/convention
decision → component-by-component pass → content translation.

### AI-assisted translation tool
> Original: "Funcion de traducción AI para cada uno"

A Sanity Studio document action that calls an AI API to auto-translate a
document (or specific fields) into a target locale, so editors don't retype
every field by hand when adding a new language version. Needs: which AI
provider/API key, which fields/document types it covers, whether it's a
one-click "translate this doc" action or something more granular, and how
review/editing of the AI output fits into the existing
`document-internationalization` workflow. Not scoped in detail yet — just a
placeholder for "we want this."
